# Interpreting development recovery evidence

These rules guide the next engineering decision; they do not change a running policy or certify publication readiness. Written during common-state-dev-003 execution, after the first two questions' terminals were visible but before its complete scores/catalog audit. The actual pre-inference selection/source freeze is recorded separately in that study's manifest and selection protocol.

| Observation | Interpretation and next action |
|---|---|
| Initial program rejected; later answer exactly matches official set | Record an observed rejection-to-exact transition and all extra costs. Obtain independent semantic acceptance before calling it certified recovery; no eligible-case rate follows automatically. |
| Exact-answer program exists in a fully queried catalog, but selection or gate fails | Inspect the initial choice, failure reason and remaining budget. Distinguish a wrong choice from an uncalibrated gate and from a truly feasible acceptable continuation. Never supply catalog-oracle scores to inference. |
| No exact answer option found in a fully evaluated bounded catalog | Resampling that catalog cannot produce an official exact answer. Diagnose linking, shortlist, root/schema coverage and grammar. Broader acquisition requires a separately specified/frozen mechanism; do not merely increase retry count. |
| Some candidate queries incomplete or timed out | Retain unknown coverage. Failure to find an exact candidate is not proof of absence. |
| Fixed and repair both answer correctly without rejection | The case provides no observed repair opportunity. It does not validate a recovery benefit or the rejection-reason ablation. Keep the negative branch-coverage result. |
| Semantic-gate-off answers without final audit | This records the intervention. It does not establish that verification is unnecessary or harmful; check semantics and costs independently. |
| Valid index mapping with an extra/wrong declared entity | Representation integrity passed; answer semantics failed or remain unknown. Preserve raw declarations and do not repair them retrospectively using gold. |

Report all frozen outcomes and purpose-selected denominators. Keep inspected-case engineering evidence separate from untouched-cohort evaluation. The100-question reservation and official test remain unrun; independent review, the larger executable freeze and release decisions stay open.
