## Implemented changes

- A separate runtime enforces a closed copied-anchor grammar for parent/child direction. For recognized single-anchor questions, the model cannot override the declared predicate orientation. Unknown/nested phrasing and incorrect parser category/anchor can remain unhandled; no general semantic verifier is claimed.
- Up to three bounded queries discover one-hop endpoint edges back to the primary anchor. Only observed containment bindings are added and prioritized within the20-entry catalog cap. The new compiler supports primary-anchor conjunctions while still binding all secondary anchors; each conjunction edge has its own recorded witness.
- After an explicit closed-obligation rejection, version2 removes every remaining candidate violating that same necessary condition before the second model choice. This is basic hand-designed constraint propagation, with no benchmark answer, question-ID rule, reward model or extra model call for pruning.
- The v11 controller/compiler and v16 semantic module are unchanged. New runtime/source snapshots, seven-module isolated restoration, manifest hashing, actual provider/query ledgers and a grammar-aware independent witness auditor preserve reproduction.
